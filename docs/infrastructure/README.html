Scope technique

  • Resource Group dedie au projet ERPNext.
  • VNet 10.20.0.0/16 et subnet AKS 10.20.0.0/22.
  • Cluster AKS avec node pool systeme.
  • ACR, Key Vault, Log Analytics, Managed Identity.

Usage rapide

cd infrastructure/terraform
terraform init
terraform validate
terraform plan
Important: aucun secret ne doit etre versionne. Les fichiers sensibles (tfvars, tfstate, credentials) restent exclus du depot.

Objectif

Avoir une base documentaire claire, partageable en equipe et exploitable en audit technique, pour preparer les prochaines phases: bootstrap AKS, GitOps, deploiement ERPNext et observabilite.
